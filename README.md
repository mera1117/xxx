# 倒班助手（原生 iOS 本地版）

这是基于 SwiftUI 的独立重写项目，目标是提供无广告、本地存储的倒班日历。

## 当前实现
- 月历和日期班次展示
- 自定义循环规则（白班、中班、夜班、休息、请假、自定义）
- 指定日期覆盖/恢复循环规则
- 月度工作、休息、夜班、请假统计
- 本地团队成员名单
- 本地通知权限和已手动设置班次的提醒
- JSON 本地备份导出/导入
- 不集成广告 SDK、不要求注册账号、不上传排班数据

## 重要限制
- 这是第一版源代码工程，不是已编译或已验证的 IPA。
- 目前无法在当前环境启动 iOS Simulator 或真机验证。
- 团队模块为本地名单管理，不包含多人同步、聊天、组织云服务。
- 统计暂未加入工资/加班费算法；需要用户提供工资规则后再实现。
- 桌面小组件尚未加入 Xcode Widget Extension target；可在后续版本补充。
- 通知目前对未来 21 天内、已手动设置具体时间的班次安排固定提前 60 分钟提醒。系统通知权限、时间格式和后台行为仍需真机测试。

## 用 Xcode 打开
1. 使用 macOS 和 Xcode 15 或更新版本。
2. 打开 `ShiftAssistantNative.xcodeproj`。
3. 选择 `ShiftAssistant` scheme 和一个 iPhone Simulator。
4. 在 Signing & Capabilities 中选择你自己的 Team（仅在安装到真机时需要）。
5. 构建并运行。

## 数据
应用数据存放于应用沙盒的 Application Support/shift-data.json。卸载应用可能导致本地数据被删除，建议通过“设置 - 导出本地备份”保存副本。
